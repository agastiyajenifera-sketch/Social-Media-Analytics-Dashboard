Social Media Analytics Dashboard - Final 7 CSV Dataset

Title: Social Media Analytics Dashboard

The seven CSV files were structured to match the project problem statement:
posts, post types/content, platforms, dates/times, engagement, reach, impressions,
audience demographics/interests/locations, campaigns and influencers.

Derived columns:
- Content_Category: derived from Post_Type/Post_Content for analysis.
- Total_Engagement = Likes + Comments + Shares.
- Calculated_Engagement_Rate = Total_Engagement / Reach * 100.
- Engagement_per_Impression = Total_Engagement / Impressions * 100.
- Reach_Efficiency = Reach / Impressions * 100.
- Performance_Level: Low (<5%), Medium (5%-<10%), High (>=10%).

The source dataset does not contain followers, follower growth, or structured hashtags,
so these were NOT fabricated into this seven-file source-aligned package.
