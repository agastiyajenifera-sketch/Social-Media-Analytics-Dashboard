# 📊 Social Media Analytics Dashboard
📌 Project Overview

The Social Media Analytics Dashboard is a Business Intelligence project developed using Excel, SQL, and Power BI to analyze social media performance across multiple platforms. The project integrates data from various datasets such as Posts, Engagement, Audience, Platforms, Locations, Campaigns, and Influencers to transform raw social media data into meaningful business insights.

The dashboard helps businesses, marketers, and content creators monitor key performance indicators (KPIs), understand audience behavior, evaluate content and campaign performance, compare platform effectiveness, and make data-driven marketing decisions.

🎯 Problem Statement

Social media platforms generate huge amounts of data related to posts, audience demographics, engagement, campaigns, influencers, reach, impressions, likes, comments, shares, and overall content performance. However, raw data spread across multiple datasets makes it difficult to identify meaningful trends and business insights.

This project addresses the challenge by integrating and analyzing social media data using Excel, SQL, and Power BI to provide an interactive dashboard that helps users:

Monitor engagement performance
Identify high-performing content
Compare platform performance
Understand audience preferences
Evaluate campaign effectiveness
Optimize social media strategies
